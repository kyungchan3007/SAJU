# 라우트 맵

Next.js App Router 기반이며 `apps/web/src/app` 디렉토리 구조가 곧 URL 구조입니다.

## 라우트 그룹

| 그룹 | 경로 | 설명 |
|------|------|------|
| `(main)` | `/home`, `/saju`, `/mypage`, ... | 메인 레이아웃 (네비게이션 포함) |
| `(auth)` | `/login` | 인증 레이아웃 (네비게이션 없음) |

## 페이지 목록

| URL | 파일 | 설명 |
|-----|------|------|
| `/` | `app/page.tsx` | 루트 → `/home` 리다이렉트 |
| `/home` | `app/(main)/home/page.tsx` | 메인 홈 |
| `/login` | `app/(auth)/login/page.tsx` | 카카오 로그인 |
| `/saju` | `app/(main)/saju/page.tsx` | 사주 입력 |
| `/saju/result` | `app/(main)/saju/result/page.tsx` | 사주 결과 조회 |
| `/compatibility` | `app/(main)/compatibility/page.tsx` | 궁합 결과 · 결제 |
| `/location` | `app/(main)/location/page.tsx` | 위치 추천 · 지도 |
| `/community` | `app/(main)/community/page.tsx` | 커뮤니티 관심신청 |
| `/food` | `app/(main)/food/page.tsx` | 음식 추천 |
| `/taro` | `app/(main)/taro/page.tsx` | 타로 (준비 중) |
| `/mypage` | `app/(main)/mypage/(with-sidebar)/page.tsx` | 마이페이지 메인 |
| `/mypage/account` | `app/(main)/mypage/(with-sidebar)/account/page.tsx` | 계정 설정 |
| `/mypage/saju-manage` | `app/(main)/mypage/(with-sidebar)/saju-manage/page.tsx` | 내 사주 관리 |
| `/mypage/jeongtongsaju` | `app/(main)/mypage/(with-sidebar)/jeongtongsaju/page.tsx` | 정통사주 |
| `/mypage/zodiac-compatibility` | `app/(main)/mypage/(with-sidebar)/zodiac-compatibility/page.tsx` | 띠별 궁합 |
| `/mypage/traditional-fortune` | `app/(main)/mypage/(fullscreen)/traditional-fortune/page.tsx` | 정통사주 전체화면 |
| `/mypage/year-fortune` | `app/(main)/mypage/(fullscreen)/year-fortune/page.tsx` | 신년운세 전체화면 |
| `/auth/restore` | `app/auth/restore/page.tsx` | 탈퇴 복구 안내 |

## 보호 서비스 진입 정책

사주 기본정보가 필요한 서비스는 로그인 여부와 사주 프로필 보유 여부에 따라 진입을 분기합니다.

| 서비스 | 직접 진입 경로 | 사주 기본정보 없음 |
|------|------|------|
| 정통사주 풀이 | `/mypage/traditional-fortune` | `/saju?next=/mypage/traditional-fortune&forceInput=1` |
| 궁합 | `/compatibility` | `/saju?next=/compatibility&forceInput=1` |
| 오늘의 메뉴 | `/food` | `/saju?next=/food&forceInput=1` |
| 커뮤니티 | `/community` | `/saju?next=/community&forceInput=1` |
| 위치 추천 | `/location` | `/saju?next=/location&forceInput=1` |

- 비로그인 사용자는 먼저 `/login?next=원래 서비스`로 이동합니다.
- 로그인 후에도 사주 기본정보가 없으면 `/saju` 입력으로 진입을 통일합니다.
- `/saju` 완료 후에는 `next` 기준으로 원래 서비스에 복귀합니다.

## 마이페이지 중첩 레이아웃

마이페이지는 2개의 중첩 레이아웃 그룹으로 분리합니다.

```
mypage/
├── layout.tsx                   ← 인증 체크
├── (with-sidebar)/
│   ├── layout.tsx               ← 사이드바 포함
│   ├── page.tsx                 ← /mypage
│   ├── account/
│   ├── saju-manage/
│   ├── jeongtongsaju/
│   └── zodiac-compatibility/
└── (fullscreen)/
    ├── traditional-fortune/     ← 전체화면 풀이
    └── year-fortune/            ← 전체화면 풀이
```
