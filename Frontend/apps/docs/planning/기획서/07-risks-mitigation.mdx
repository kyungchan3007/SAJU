# 7. 위험 요소 & 완화 전략

## 위험 요소 분석

| 위험 요소 | 가능성 | 영향도 | 완화 전략 |
|---------|-------|-------|---------|
| 초기 사용자 수 부족으로 매칭 풀이 얕음 | 높음 | 치명적 | 출시 전 사전 가입 이벤트 운영. 카카오 채널·SNS 광고로 초기 풀 확보. DAU 300명 미만이면 추천 알고리즘 기준 완화 (궁합 점수 하한 낮춤). |
| Ablecity API 장기 장애 | 낮음 | 치명적 | Circuit Breaker + Retry. 사주 데이터는 DB 캐싱. 장애 시 '점검 중' 안내 + 이미 등록된 사용자는 정상 이용. |
| 로테이션 소개팅 오프라인 공간 확보 실패 | 중간 | 높음 | 온라인 화상 소개팅(Zoom·Meet 링크 제공)으로 대체 플랜 준비. 파트너 카페·공간 2곳 이상 사전 계약. |
| 채팅 비매너 사용자로 인한 커뮤니티 신뢰 하락 | 중간 | 높음 | 신고 기능(Should S-04) MVP 포함 검토 상향. 신고 3회 이상 시 자동 매칭 중지. 어드민 24h 모니터링. |
| WebSocket 채팅 단일 인스턴스 한계 | 낮음 (초기) | 중간 | 동시 연결 500개 초과 시 즉시 ALB + 추가 인스턴스 투입. 스케일아웃 시 Redis Pub/Sub으로 메시지 브로커 전환. |
| 개인정보·보안 이슈 (프로필 사진·채팅) | 낮음 | 치명적 | S3 프라이빗 버킷 + Presigned URL. 채팅 내용 서버 저장 최소화. 출시 전 보안 체크리스트 점검. |
| 성별 불균형 (여성 부족) | 중간 | 높음 | 여성 무료 참가 이벤트 운영. 여성 친화적 UX·안전 기능 강조. 초대 코드 이벤트로 지인 초대 유도. |
| 사주 계산 정확도 오류로 궁합 점수 신뢰 하락 | 낮음 | 치명적 | W3 완료 시 100케이스 검증. 오류 발견 시 Ablecity 파라미터 즉시 재확인. |

## 출시 전 체크리스트

### 보안·개인정보
- ☐ HTTPS 적용 (Route53 + ACM)
- ☐ HttpOnly Cookie · Token Rotation 확인
- ☐ 프로필 사진 S3 Presigned URL 접근 제어
- ☐ 개인정보 처리 방침 · 이용 약관 페이지 게시
- ☐ 만 18세 미만 가입 제한 처리

### 기능
- ☐ 사주 100케이스 정확도 검증
- ☐ 상호 좋아요 → 매칭 → 채팅방 생성 엔드투엔드 테스트
- ☐ 로테이션 소개팅 참가 신청 → 그룹 배정 플로우 테스트
- ☐ Ablecity 비동기 콜백 로컬·EC2 양쪽 확인
- ☐ 채팅 WebSocket 동시 연결 부하 테스트

### 운영
- ☐ CloudWatch 알람 설정 (CPU 70%, 에러율 1%)
- ☐ RDS 자동 백업 활성화
- ☐ 신고·차단 기능 어드민 대시보드 확인
- ☐ 오프라인 이벤트 장소 파트너 계약 완료

### 커뮤니티 안전
- ☐ 신고 → 자동 경고 → 매칭 중지 플로우 확인
- ☐ 비매너 행동 기준 정책 문서화 및 앱 내 노출
- ☐ 어드민 모니터링 담당자 지정
