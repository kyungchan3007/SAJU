# 1. 문제 정의

## 배경 및 시장 기회

### 시장 규모
- **국내 온라인 데이팅 앱 시장**: 약 500만 명 (20-40세 기준)
- **소개팅 시장**: 약 300억 원 (오프라인 기준)
- **온라인 매칭 시장 성장률**: 연평균 15%

### 소비자 니즈
1. **기존 앱들의 한계**
   - Tinder, Bumble: 외모 기반 스와이핑 → 깊이 있는 관계 형성 어려움
   - 소개팅 플랫폼: 오프라인 이벤트 기반 → 시간·장소 제약
   - 심리 테스트 앱: 정보만 제공 → 실제 매칭 기능 없음

2. **미충족 니즈**
   - "나와 잘 맞는 사람을 찾고 싶은데, 외모가 아닌 다른 기준이 있을까?"
   - "사주·궁합처럼 전통적 기준으로 상대를 알고 싶다"
   - "온라인도, 오프라인도 함께할 수 있는 서비스가 있을까?"

---

## 해결하려는 핵심 문제

**"사주 기반 매칭으로 깊이 있는 관계를 만드는 소개팅 서비스"**

1. **매칭 알고리즘의 다양화**
   - 기존: 프로필 스코어 + 지역 근접도
   - 신규: 사주 궁합 + 기운 호환도 + 프로필 정보

2. **신뢰 기반 커뮤니티**
   - 카카오 인증 (실명 기반) → 보안과 신뢰
   - 신고·차단 시스템 → 안전한 환경

3. **온오프라인 통합 경험**
   - 온라인 프로필 기반 매칭 (1:1)
   - 오프라인 로테이션 소개팅 이벤트

---

## 핵심 가치 제안

| 기능 | 기존 앱 | 사주 기반 소개팅 |
|------|--------|------------|
| 매칭 기준 | 외모, 키, 직업 | **사주, 궁합, 기운** + 프로필 |
| 신뢰도 | 중간 (가짜 계정 많음) | **높음 (카카오 인증)** |
| 소개팅 형식 | 온라인만 | **온오프라인 하이브리드** |
| 커뮤니티 안전 | 약함 | **신고·차단 시스템** |

---

## 비즈니스 모델

### 수익 구조
1. **로테이션 소개팅 참가권** (2단계)
   - 월 1회 오프라인 이벤트 개최
   - 참가권: 5,000~10,000원
   - 목표: 월 50명 참가 = 월 250,000~500,000원

2. **좋아요 충전** (3단계)
   - 프리미엄 좋아요 충전
   - 월 활성 사용자당 ARPU 5,000원 목표

### 성장 전략
- **1단계 (MVP)**: 온라인 매칭 + 로테이션 소개팅 (오프라인)
- **2단계**: 모바일 앱 출시, 좋아요 충전 기능
- **3단계**: 커뮤니티 피드, 포인트 시스템, 다국어 지원

## 초기 타겟 유저

- **연령**: 20-35세
- **지역**: 대한민국 (서울·경기 중심)
- **성격**: 새로운 만남을 원하되, 깊이 있는 관계를 추구하는 사람
- **신념**: 사주·궁합에 관심 있거나 열린 마음의 사람
- **디지털 리터러시**: 높음 (카카오 인증 사용 경험 있음)
