# 2. 타겟 사용자 & 페르소나

## 2-1. 타겟 사용자 정의

### 주요 특징
- **연령**: 20-35세
- **성별**: 남녀 동등 (1:1 매칭 기반)
- **거주지**: 대도시 (서울, 경기, 인천 중심)
- **직업**: 회사원, 프리랜서, 대학생 (스마트폰 활용도 높음)
- **사주 관심도**: 약간 있음~높음 (무관심층도 수용)
- **데이팅 경험**: 기존 앱 사용 경험 있음

### 선택 이유
1. **시장 크기**: 국내 20-35세 약 700만 명 (미혼 기준)
2. **디지털 친숙**: 카카오톡 사용률 95%+
3. **고액결제**: 소개팅 관심도가 높고 결제 의향 높음
4. **초기 임계값**: 500-1000명으로 서비스 론칭 가능

---

## 2-2. 3가지 페르소나

### 페르소나 1: 김지은 (28, 여성, 회사원)

**배경**
- 대기업 마케팅팀 근무
- 직급: 과장
- 연봉: 4000만원
- 거주지: 서울 강남구

**특징**
- 데이팅 앱 경험: Tinder, 소개팅 플랫폼 2년 사용
- 사주 관심도: 높음 (친구들과 사주 이야기 자주 함)
- 결혼 의향: 3년 내 결혼 생각 있음
- 스마트폰 사용: 1일 4시간

**니즈**
- "외모만으로 판단하는 게 싫어. 궁합이 맞는 사람 만나고 싶어"
- "진짜 나와 맞는 사람이 누군지 알고 싶다"
- "신뢰할 수 있는 상대와 만나고 싶다"

**사용 시나리오**
1. 앱 첫 실행 → 사주 등록 (3분)
2. 홈: 추천 프로필 3명 보기 (4-5명 중 1-2명에게 좋아요)
3. 매칭된 상대와 채팅 (30분)
4. 1주일 후 로테이션 소개팅 이벤트 신청 (오프라인)

---

### 페르소나 2: 이준혁 (30, 남성, 시스템 엔지니어)

**배경**
- 중견 IT 기업 근무
- 직급: 팀장
- 연봉: 6000만원
- 거주지: 경기 성남시

**특징**
- 데이팅 앱 경험: Bumble 1년, 기존 앱 저조
- 사주 관심도: 약간 있음 (회의적이지만 열려있음)
- 결혼 의향: 없음 (관계만 원함)
- 스마트폰 사용: 1일 3시간

**니즈**
- "프로필만으로는 상대를 잘 모른다. 더 깊이 알아가고 싶다"
- "카톡만 하다가 만나는 게 부담스럽다"
- "안전하고 신뢰할 수 있는 여성 만나고 싶다"

**사용 시나리오**
1. 앱 실행 → 사주 등록 (2분, 도움말 건너뜀)
2. 홈: 추천 프로필 슥~ 훑기 (좋아요 1명)
3. 채팅방에서 1:1 대화 (1-2주)
4. 카페에서 오프라인 만남 (채팅 → 오프라인 전환)

---

### 페르소나 3: 박소연 (24, 여성, 대학원생)

**배경**
- 서울대 대학원 심리학과 2학년
- 아르바이트: 카페 (주 10시간)
- 거주지: 서울 관악구
- 형편: 학자금 대출 중

**특징**
- 데이팅 앱 경험: 없음 (친구 권유로 시작)
- 사주 관심도: 낮지만 열려있음
- 결혼 의향: 아직 생각 안 함
- 스마트폰 사용: 1일 5시간 (SNS 중심)

**니즈**
- "새로운 사람 만나고 싶은데, 편하게 시작하고 싶다"
- "사주가 뭔지도 배우고 싶어"
- "온라인에서 편하게 알아가다가 오프라인도 괜찮으면 만나자"

**사용 시나리오**
1. 친구 초대코드로 가입 (온보딩)
2. 사주 등록 + 튜토리얼 (도움말 읽음)
3. 채팅만 3주 진행 (오프라인 약속 꺼림)
4. 로테이션 소개팅 이벤트 한 번 참가 후 탈퇴 가능성

## 2-3. 핵심 사용자 여정 (User Journey)

### 온보딩 → 매칭 → 채팅 → 오프라인 만남

```
Day 1: 가입 & 사주 등록
├─ 카카오 로그인 (1분)
├─ 프로필 작성 (5분)
├─ 사주 입력: 생년월일 (30초)
└─ 사주 정보 확인 (기운 설명, 연간 운세)

Day 2-3: 매칭 탐색
├─ 홈 화면: 추천 프로필 보기 (3-5명/일)
├─ 좋아요 보내기 (1-2명/일)
└─ 매칭 확인 (상호 좋아요 → 채팅방 열림)

Day 4-14: 채팅 및 관계 형성
├─ 채팅방에서 1:1 대화 (매일 10-30분)
├─ 프로필 정보로 상대 더 알아가기
├─ 오프라인 만남 제안 (자발적 또는 채팅 유도)
└─ 로테이션 소개팅 이벤트 참가 고민

Day 15+: 오프라인 만남
├─ 카페/밥 약속 (개인 주도)
├─ 로테이션 소개팅 이벤트 (서비스 주도)
└─ 관계 지속 또는 서비스 이탈
```
