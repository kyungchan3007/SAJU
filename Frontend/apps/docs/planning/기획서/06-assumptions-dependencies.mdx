# 6. 가정 & 의존성

## 6-1. 가정 (Assumptions)

- Ablecity API는 SLA 99.5% 이상을 제공하며, 주요 장애 시 1시간 이내 복구된다.
- OpenAI GPT-4o-mini의 한국어 사주 해설 품질이 사용자 불만족률 5% 미만을 달성한다.
- 카카오 플랫폼 정책(OAuth2)이 MVP 출시 기간 동안 변경되지 않는다.
- 국내 20~35세 소개팅 타겟의 80% 이상이 카카오 계정을 보유하고 있다.
- 로테이션 소개팅 이벤트는 오프라인 장소 파트너십을 통해 월 1회 이상 개최 가능하다.
- 초기 트래픽은 EC2 단일 인스턴스로 처리 가능하다 (동시 사용자 200명 기준).
- WebSocket 채팅은 단일 인스턴스에서 동시 연결 500개까지 처리 가능하다.

## 6-2. 외부 의존성

| 의존 항목 | 목적 | 장애 시 대응 | 준비 기한 |
|---------|------|----------|---------|
| Ablecity API | 사주 8자·오행·기운·궁합 점수 | Circuit Breaker, 기존 캐시 폴백 | 출시 전 |
| OpenAI API | 기운 LLM 해설, 전통 운세 생성 | 재시도 + 기본 텍스트 폴백 | 출시 전 |
| 카카오 OAuth2 | 소셜 로그인 | 서비스 전면 중단 → 점검 안내 | W1 완료 |
| AWS EC2·RDS·S3 | 서버·DB·파일 저장 | RDS 자동 백업, 수동 복구 | W1 완료 |
| GitHub Actions | CI/CD 자동 배포 | 수동 Docker 배포 | W1 완료 |
| 오프라인 장소 파트너 | 로테이션 소개팅 이벤트 공간 | 온라인 화상 소개팅으로 대체 | 2단계 전 |
