# 3. 핵심 기능

기능을 MoSCoW 방식으로 분류: Must Have, Should Have, Nice to Have

---

## 3-1. Must Have (필수 기능, 13개)

**없으면 서비스가 성립하지 않음**

| # | 기능명 | 상세 | 담당 | 우선순위 |
|----|--------|------|------|---------|
| M-01 | 카카오 로그인 | OAuth2 기반, 실명 인증 | 백엔드 | P0 |
| M-02 | 사주 등록 | 생년월일(양력/음력 선택) → 8자 저장 | 백엔드, 프론트 | P0 |
| M-03 | 사주 정보 조회 | 8자, 오행, 기운(5단계 평점) | 프론트 | P0 |
| M-04 | 기운 설명 | "당신의 기운은 목(木) 기질로..." (LLM 생성) | 백엔드, 프론트 | P0 |
| M-05 | 연간 운세 | 올해 전망 3-4문단 (LLM 생성) | 백엔드, 프론트 | P0 |
| M-06 | 전통 운세 | 십간십이지 해석 (DB 저장, 선택적 LLM) | 백엔드, 프론트 | P0 |
| M-07 | 매칭 프로필 | 프로필 사진, 자기소개, 직업, 위치, 사주 | 프론트 | P0 |
| M-08 | 추천 알고리즘 | 사주 궁합도(1~100) + 위치 + 프로필 정보 | 백엔드 | P0 |
| M-09 | 좋아요 기능 | 프로필에 좋아요 버튼 | 프론트 | P0 |
| M-10 | 매칭 확인 | 상호 좋아요 → 채팅방 자동 생성 | 백엔드, 프론트 | P0 |
| M-11 | 1:1 채팅 | WebSocket 기반 실시간 메시지 | 백엔드, 프론트 | P0 |
| M-12 | 프로필 관리 | 프로필 사진, 자기소개, 직업 수정 | 프론트 | P0 |
| M-13 | 로테이션 소개팅 참가 | 이벤트 조회 → 신청 → QR 체크인 | 백엔드, 프론트 | P0 |

---

## 3-2. Should Have (높은 우선순위, 4개)

**품질에 직접 영향을 주는 기능. 1-2단계에서 추가 가능**

| # | 기능명 | 상세 | 우선순위 | 대상 단계 |
|----|--------|------|---------|----------|
| S-01 | 좋아요 상호 확인 | 나에게 좋아요를 보낸 프로필 리스트 | P1 | 2단계 |
| S-02 | 프로필 신고 | 비매너, 사기, 음란물 신고 → 어드민 검토 | P1 | 2단계 |
| S-03 | 매칭 상대 차단 | 채팅 중 상대 차단 → 연락 차단 | P1 | 2단계 |
| S-04 | 채팅 알림 | 새 메시지 푸시 알림 | P2 | 2단계 |

---

## 3-3. Nice to Have (선택 기능, 5개)

**있으면 좋지만 초기 론칭에는 불필수. 3단계 이후 검토**

| # | 기능명 | 상세 | 대상 단계 |
|----|--------|------|----------|
| N-01 | 커뮤니티 피드 | 사주 팁, 운세 뉴스, 사용자 후기 게시판 | 3단계 |
| N-02 | 좋아요 충전 | 프리미엄 좋아요 구매 (월 5회 → 무제한) | 3단계 |
| N-03 | 포인트 시스템 | 미션(프로필 완성 등) → 포인트 → 충전 | 3단계 |
| N-04 | SNS 공유 | 운세/프로필 카드 카카오톡 공유 | 3단계 |
| N-05 | 모임 기능 | 매칭 후 그룹 모임 추천 | 3단계 |

---

## 3-4. 기능 마일스톤

### MVP (1단계, W1~W8)
- ✅ M-01~M-13 (13개 필수 기능)
- 목표: 온라인 매칭 + 로테이션 소개팅

### 2단계 (W9~W16)
- ✅ S-01~S-04 (4개 Should Have)
- ✅ 좋아요 충전 결제 시스템 (기초)
- 목표: 사용자 경험 고도화

### 3단계 (W17~)
- ✅ N-01~N-05 (5개 Nice to Have)
- ✅ 다국어 지원 (영어, 일본어)
- ✅ SNS 공유 (개선)
- 목표: 커뮤니티화 및 바이럴 성장

```
│

```
