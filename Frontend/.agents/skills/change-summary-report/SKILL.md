# 변경 요약 보고 스킬

## 사용 조건

- 사용자가 현재 git 변경분 정리를 요청한다.
- 사용자가 타입(`feat`, `refactor`, `fix`, `chore`)을 지정하면 해당 타입 기준으로 정리한다.
- 사용자가 파일 경로 제외를 요청하면 파일 경로를 쓰지 않는다.

## 출력 규칙

- 존댓말 문장형 금지 (`~했습니다`, `~합니다`, `~입니다` 금지)
- 제목형(명사형/짧은 서술형)으로 간결하게 작성
- 기본 블릿은 `>` 형태 우선

## 타입별 템플릿 규칙

- `feat` / `fix` / `chore`:
  - 기본 4개 항목 템플릿 사용
- `refactor`:
  - 아래 refactor 전용 템플릿만 사용
  - 기본 4개 항목 템플릿 출력 금지

## 기본 4개 항목 템플릿

### 어떤기능인가요

> 사용자 관점의 변경 기능/경험 1~2줄 요약

### 작업상세내용

> 기능 단위 제목형 항목 나열
> 파일 경로 대신 컴포넌트/화면/역할 중심 표현 사용
> 검증 결과 또는 잔여 리스크 포함 가능

### 요약본

> 전체 변경 2~4줄 압축 요약

### 커밋메시지(한글)

> 타입 접두어 포함 한글 커밋 제목
