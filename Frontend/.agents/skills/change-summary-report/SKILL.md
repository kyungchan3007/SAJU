# 변경 요약 보고 스킬

## 사용 조건

- 사용자가 현재 git 변경분을 확인해 작업 내용을 정리해 달라고 요청한다.
- 사용자가 항목명을 지정하지 않으면 아래 4개 항목을 기본으로 사용한다.
- 사용자가 파일 경로 제외를 요청하면 파일 경로를 쓰지 않는다.

## 작성 형식

- 각 항목의 본문은 존댓말 문장형으로 쓰지 않는다.
- `~했습니다`, `~합니다`, `~입니다` 같은 종결 표현 대신 제목처럼 간결한 명사형 또는 짧은 서술형으로 정리한다.
- 예: `공통 히어로 레이아웃 적용`, `중복 padding 제거`, `타입 검사 및 린트 통과`

### 어떤기능인가요

> 현재 변경분이 사용자 관점에서 어떤 기능 또는 화면 경험을 바꾸는지 한두 줄의 제목형 요약으로 적는다.

### 작업상세내용

> 세부 작업을 기능 단위의 제목형 항목으로 나눠 작성한다.
> 변경된 파일 경로 대신 역할, 컴포넌트명, 화면 영역, 스타일 토큰처럼 사용자가 이해할 수 있는 표현을 쓴다.
> 검증 결과나 남은 리스크가 있으면 마지막에 포함한다.

### 요약본

> 전체 변경을 2~4줄로 압축한다.

### 커밋메시지(한글)

> 타입: 한글 커밋 제목

## 이번 변경 요약 예시

### 어떤기능인가요

> 전역 UI 테마의 SAJU:ME 보라색 브랜드 톤 전환
> 전역 네비게이션, 공용 버튼, 페이지 배경, 카드/입력 스타일, Footer 디자인 정리

### 작업상세내용

> 전역 CSS 변수와 Tailwind 토큰의 보라색 브랜드 팔레트 재정의
> 공용 버튼 primary, secondary, outline, ghost 스타일의 보라색 그라디언트 및 테두리 기준 정리
> 전역 네비게이션 로고의 SAJU:ME 형태 변경 및 active 상태의 보라색 기준 정리
> 위치추천, 타로, 커뮤니티, 마이 메뉴 유지 및 마이 메뉴의 로그인 상태별 연결 분기

> 공용 Button과 Footer의 폴더형 UI 모듈 구조 정리 및 export/import 경로 정합성 확보

### 요약본

> SAJU:ME 보라색 브랜드 테마의 전역 스타일, Tailwind 설정, 버튼, 네비게이션, Footer 반영
> 전역 레이아웃의 inline 배경색 제거 및 CSS 테마 토큰 사용
> location, taro, community 메뉴 구성 유지 및 마이 메뉴의 우측 프로필/로그인 흐름 분리
