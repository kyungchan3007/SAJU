# 변경 요약 보고 스킬

## 사용 조건

- 사용자가 현재 git 변경분을 확인해 작업 내용을 정리해 달라고 요청한다.
- 사용자가 항목명을 지정하지 않으면 아래 4개 항목을 기본으로 사용한다.
- 사용자가 파일 경로 제외를 요청하면 파일 경로를 쓰지 않는다.

## 작성 형식

### 어떤기능인가요

> 현재 변경분이 사용자 관점에서 어떤 기능 또는 화면 경험을 바꾸는지 한두 문장으로 적는다.

### 작업상세내용

> 세부 작업을 기능 단위로 나눠 작성한다.
> 변경된 파일 경로 대신 역할, 컴포넌트명, 화면 영역, 스타일 토큰처럼 사용자가 이해할 수 있는 표현을 쓴다.
> 검증 결과나 남은 리스크가 있으면 마지막에 포함한다.

### 요약본

> 전체 변경을 2~4줄로 압축한다.

### 커밋메시지(한글)

> 타입: 한글 커밋 제목

## 이번 변경 요약 예시

### 어떤기능인가요

> 전역 UI 테마를 기존 스케치/종이 톤에서 SAJU:ME 보라색 브랜드 톤으로 전환하는 작업입니다.
> 전역 네비게이션, 공용 버튼, 페이지 배경, 카드/입력 스타일, Footer를 새 디자인 방향에 맞게 정리했습니다.

### 작업상세내용

> 전역 CSS 변수와 Tailwind 토큰을 보라색 브랜드 팔레트로 재정의했습니다.
> 공용 버튼의 primary, secondary, outline, ghost 스타일을 보라색 그라디언트와 보라색 테두리 중심으로 변경했습니다.
> 전역 네비게이션 로고를 SAJU:ME 형태로 바꾸고, 데스크탑 active 상태와 모바일 하단 탭 active 상태를 보라색 기준으로 정리했습니다.
> 네비게이션 메뉴에 위치추천, 타로, 커뮤니티, 마이 항목을 유지하고, 마이 항목은 로그인 상태에 따라 마이페이지 또는 로그인으로 연결되도록 정리했습니다.
> Footer를 새로 추가해 브랜드 로고, 저작권, 약관/개인정보/문의 링크 영역을 전역 레이아웃 하단에 배치했습니다.
> 공용 Button과 Footer를 폴더형 UI 모듈 구조로 정리하고, 관련 export/import 경로를 맞췄습니다.

### 요약본

> SAJU:ME 보라색 브랜드 테마를 전역 스타일, Tailwind 설정, 버튼, 네비게이션, Footer에 반영했습니다.
> 전역 레이아웃은 inline 배경색을 제거하고 CSS 테마 토큰을 사용하도록 바뀌었습니다.
> 네비게이션은 location, taro, community를 포함한 메뉴 구성을 유지하며, 마이 메뉴만 우측 프로필/로그인 흐름으로 분리했습니다.
